# 模型部署配置

DisciMind 使用 LangChain/LangGraph 调用阿里云百炼兼容接口，不在源码包中分发第三方基础模型权重。`bailian.env.example` 是后端实际读取的配置字段，可用于比赛自有百炼账号或兼容的受控服务。

## 使用方法

1. 复制 `bailian.env.example` 中需要的字段到 `backend/.env`，或在管理员端“AI 配置”中录入供应商。
2. 填写自己的 API Key、模型和可选知识库 ID；不得把填充后的文件提交到 Git。
3. 重启后端，通过管理员端健康检查验证模型连接。

Windows 评委便携版默认启用数据库加密配置中心，并关闭环境变量兜底。评委可登录 `admin_demo` 后在 AI 配置页面录入临时密钥；密钥仅保存在本机评审数据库。生产部署还必须配置独立的 `AI_CONFIG_ENCRYPTION_KEY`。

未配置模型时系统不会伪造模型响应，依赖模型的功能会返回明确的未配置状态。课程、权限、数据看板、智能体广场、编译器以及 PPT 演示模式仍可独立验收。
