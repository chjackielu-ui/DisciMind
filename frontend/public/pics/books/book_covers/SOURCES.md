# Course cover sources

The course covers in this directory are stored locally so the student course page does not depend on third-party availability.

- `data-structures.webp` — *An Open Guide to Data Structures and Algorithms*, Open Textbook Library, CC BY 4.0: https://open.umn.edu/opentextbooks/textbooks/1017
- `operating-systems.webp` — *Operating Systems and Middleware: Supporting Controlled Interaction*, Open Textbook Library, CC BY-SA: https://open.umn.edu/opentextbooks/textbooks/161
- `database.webp` — *Database Design – 2nd Edition*, Open Textbook Library, CC BY: https://open.umn.edu/opentextbooks/textbooks/database-design-2nd-edition
- `computer-networks.webp` — *An Introduction to Computer Networks – Second Edition*, Open Textbook Library: https://open.umn.edu/opentextbooks/textbooks/353
- `python.webp` — *Think Python: How to Think Like a Computer Scientist – 2e*, Open Textbook Library, CC BY-NC: https://open.umn.edu/opentextbooks/textbooks/43
- `computer-science.webp` — *Computer Science I – Version 1.3.7*, Open Textbook Library, CC BY-SA: https://open.umn.edu/opentextbooks/textbooks/computer-science-i
- `probability.webp` — *Introduction to Probability*, Open Textbook Library, CC BY-SA: https://open.umn.edu/opentextbooks/textbooks/1529
