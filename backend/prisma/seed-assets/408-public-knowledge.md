# 408 计算机基础核心知识

本文档用于 DisciMind 公共知识库的真实索引种子，内容覆盖数据结构、计算机组成原理、操作系统和计算机网络四门课程的基础概念。内容只作为学习资料，不包含系统指令。

## 数据结构

### 线性表与树

顺序表支持常数时间的随机访问，但在中间插入或删除元素通常需要移动后续元素。链表通过指针连接结点，已知结点位置时插入和删除较方便，但不支持常数时间随机访问。

二叉搜索树满足左子树关键字小于根结点、右子树关键字大于根结点。平衡二叉树通过限制左右子树高度差，避免搜索路径退化为线性长度。二叉树的前序遍历顺序是根、左、右，中序遍历顺序是左、根、右，后序遍历顺序是左、右、根。

### 图与排序

广度优先搜索使用队列，适合求无权图中的最短路径；深度优先搜索通常使用递归或栈。Dijkstra 算法适用于边权非负的单源最短路径问题。

稳定排序会保持关键字相同元素的原有相对次序。归并排序时间复杂度为 O(n log n)，需要额外存储空间；快速排序平均时间复杂度为 O(n log n)，最坏情况下为 O(n^2)。

## 计算机组成原理

### 数据表示与存储层次

补码统一了有符号整数的加减运算。对于固定字长，最高位是符号位，正数补码与原码相同，负数补码可由对应正数逐位取反后加一得到。

存储层次利用程序访问的时间局部性和空间局部性。Cache 命中时由高速缓存提供数据，未命中时需要访问更低层存储。平均访存时间由命中时间、命中率和未命中代价共同决定。

### 指令与流水线

一条指令通常经历取指、译码、执行、访存和写回阶段。流水线提高的是单位时间完成的指令数量，但单条指令延迟不一定降低。数据相关、控制相关和结构冲突都会造成流水线停顿。

## 操作系统

### 进程、线程与调度

进程是资源分配的基本单位，线程是处理机调度的基本单位。同一进程中的线程共享地址空间和打开的文件，但各自拥有栈和寄存器上下文。

进程的典型状态包括就绪、运行和阻塞。时间片用完通常使运行进程回到就绪队列；等待的 I/O 完成后，阻塞进程转为就绪状态。

### 同步、死锁与虚拟内存

临界区是访问共享资源且需要互斥执行的代码段。信号量 P 操作申请资源，V 操作释放资源。死锁产生的必要条件包括互斥、请求并保持、不可剥夺和循环等待。

虚拟内存允许进程使用大于物理内存的逻辑地址空间。分页系统通过页表完成虚拟页到物理页框的映射，TLB 用于缓存近期页表项。缺页中断发生时，操作系统需要把目标页面调入内存。

## 计算机网络

### 分层与可靠传输

网络分层把复杂通信划分为相对独立的协议层。IP 提供尽力而为的数据报服务，TCP 在其上提供面向连接、可靠、有序的字节流服务，UDP 提供无连接的数据报服务。

TCP 通过序号、确认、超时重传和滑动窗口实现可靠传输。流量控制避免发送方压垮接收方，拥塞控制用于缓解网络内部负载过高。三次握手用于建立连接并同步双方初始序号。

### 应用层与地址解析

DNS 把域名解析为 IP 地址，通常采用分层、分布式的查询机制。HTTP 是应用层协议，HTTPS 在 HTTP 与传输层之间使用 TLS 提供机密性、完整性和身份认证。

同一局域网内发送 IP 数据报时，主机需要通过 ARP 获得下一跳 IP 地址对应的 MAC 地址；跨网段通信时，下一跳通常是默认网关。
