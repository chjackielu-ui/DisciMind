## 审计边界

- 数据库桥接只读取角色代码、权限键和聚合数量，不读取密钥、令牌或用户明细。
- `/admin/rbac/me` 仅依赖登录身份，用于获取当前显式权限；其余管理路由必须同时经过管理员角色和细粒度权限校验。
- 前端门禁用于体验与导航裁剪，后端权限中间件仍是最终安全边界。
