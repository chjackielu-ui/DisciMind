# 学生本人学习数据与图表协议

## 数据来源

学习分析通过 owner-bound Tool 读取当前登录学生的错题、答题/学习记录、成绩趋势、知识点掌握度、近期学习会话、学习时长和任务完成情况。查询继续使用现有 Prisma 业务表，不建立分析影子库。

## ChartSpec 1.0

`backend/src/modules/ai-assistant/chart-spec.js` 约束：

- 图表类型只允许 `line`、`bar`、`pie`、`radar`。
- 必须包含标题、指标名称、单位、时间范围、来源说明、分类轴和维度一致的 series。
- 可附受控数据表；无数据时必须包含空态原因。
- 后端把严格 ChartSpec 保存为现有 AI Artifact；前端 `artifact-renderer.js` 只将该 JSON 映射到 ECharts option，不求值代码字符串。

## 前端能力

图表消息支持自适应 ECharts、查看/收起数据表、全屏和保存 PNG。桌面、平板、手机都限制在消息气泡宽度内；表格可横向滚动但页面本身不得横向溢出。

## 真实性与异常

指标原样来自数据库并附来源和范围。本次验收发现一条历史任务记录按现有字段计算得到 `204.44%` 的分数率，这属于源数据质量异常；实现没有把它静默截断或伪造为 100%，后续应在成绩写入/数据治理层单独修正。
