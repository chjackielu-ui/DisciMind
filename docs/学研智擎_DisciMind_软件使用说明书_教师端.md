## 一、软件概述

### 1.1 主要功能

学研智擎（DisciMind）是一套面向高等教育教学、学习和科研辅助场景的 Web 应用软件。软件支持学生、教师和管理员三类角色，围绕课程、知识库、人工智能问答、多智能体、学习流、练习、错题、学习画像和教学治理形成完整的使用闭环。

| 功能模块 | 主要功能 | 用户可见结果 |
|---|---|---|
| 用户认证 | 注册、登录、退出登录、角色识别 | 登录后按角色进入对应工作台 |
| 学生首页 | 学习概览、今日智学卡、待办任务、课程进度和推荐 | 显示当前学习状态及下一步操作 |
| 课程学习 | 查看课程、章节、知识点、课程资料和学习进度 | 形成课程学习地图并记录学习位置 |
| 知识图谱 | 查看章节与知识点关系、掌握度及关联资源 | 以图谱、列表和详情面板呈现知识结构 |
| 智能练习 | 配置课程、题型、难度和题量并开始练习 | 支持作答保存、提交判分和结果查看 |
| 在线编译器 | 学生选择 C 或 Python，输入代码并提交运行 | 在控制台查看编译、运行、超时或错误结果 |
| 错题管理 | 查看错题、错误原因、复习状态和相似练习 | 错题进入错题本并支持强化学习 |
| AI 学科答疑 | 选择问答模式，输入问题并查看流式回答 | 展示回答、执行进度、引用来源和追问入口 |
| 个人知识库 | 上传 PDF、Word、Markdown 或文本资料并查看解析状态 | 文档完成上传、解析、切片和详情查看 |
| 学习流 | 创建学习目标、编排学习节点、保存并执行学习流 | 按节点生成内容、完成练习并形成学习总结 |
| 智能体广场 | 发现、搜索、收藏、复制、创建和使用智能体 | 进入智能体对话或生成学习产物 |
| 教师工作台 | 课程、教学班、作业考试、学情分析、资源和智慧备课 | 教师根据授权教学数据开展教学管理 |
| 管理员治理 | 用户、课程、知识文档、AI 配置、权限、日志和安全治理 | 管理员进行审核、配置和审计操作 |

### 1.2 技术特点

1. 软件采用前后端分离的 Web 架构，用户通过浏览器完成主要操作。
2. 软件通过学生、教师和管理员角色及权限控制区分可见菜单和可执行操作。
3. 软件支持课程知识库、来源引用、文档解析和 AI 学科答疑，回答页面可展示真实资料来源。
4. 软件提供学习流和多智能体能力，用户可创建学习目标、配置节点并按顺序执行。
5. 软件提供智能练习、自动判分、错题记录、掌握度分析和个性化学习推荐。
6. 软件提供教师学情分析、智慧备课、作业考试、课程资源和产物中心。
7. 软件提供管理员的知识文档审核、AI 供应商与模型配置、操作日志、权限和 AI 安全治理。
8. 软件对文件上传、AI 调用、权限校验、页面加载和数据保存提供状态提示、失败提示和重试入口。

## 二、运行环境与部署

### 2.1 推荐运行环境

| 环境项目 | 推荐配置 |
|---|---|
| 使用终端 | 台式机、笔记本电脑或具备现代浏览器的移动终端 |
| 操作系统 | Windows 10/11、macOS 或主流 Linux 发行版 |
| 浏览器 | Chrome、Edge、Firefox 等支持 ES6、Fetch API 和现代 CSS 的浏览器 |
| 前端运行时 | Node.js 22.12 及以上版本，npm 9 及以上版本 |
| 后端运行时 | Node.js 22.12 及以上版本 |
| 数据库 | MySQL 8.0 及以上版本，字符集建议使用 utf8mb4 |
| 显示分辨率 | 桌面端建议 1280×720 及以上 |
| 前端开发地址 | `http://localhost:5173`，以实际 Vite 启动提示为准 |
| 后端接口地址 | `http://localhost:3000`，以 `backend/.env` 中的端口配置为准 |
| 网络环境 | 能够访问前端、后端和已配置的模型、知识库及文件服务 |
| 文件格式 | PDF、DOC、DOCX、TXT、Markdown 等页面允许的格式；单文件大小以页面提示为准 |
| 运行权限 | 普通用户权限即可运行；部署、数据库初始化和服务安装需要相应管理权限 |

### 2.2 部署步骤

1. 将项目目录完整复制到部署终端，确保 `frontend`、`backend`、`storage` 和 `deploy` 等目录结构完整。
2. 安装 Node.js 22.12 及以上版本，并确认 `node -v` 和 `npm -v` 可以正常执行。
3. 安装并启动 MySQL 8.0 及以上版本，创建名为 `discimind` 的数据库并使用 `utf8mb4` 字符集。
4. 进入 `backend` 目录执行 `npm install`，安装后端依赖。
5. 进入 `frontend` 目录执行 `npm install`，安装前端依赖。
6. 在 `backend/.env` 中填写数据库连接、JWT 密钥、服务端口和需要使用的 AI 服务参数；密钥只用于部署配置，不写入说明书或截图。
7. 在 `frontend/.env` 中配置后端接口地址，开发环境通常使用 `VITE_API_BASE_URL=http://localhost:3000/api`。
8. 在 `backend` 目录执行 `npx prisma generate`，再执行数据库迁移命令创建或更新表结构。
9. 如需演示数据，执行项目提供的种子数据脚本，创建学生、教师、管理员账号及课程、题目和学习记录。
10. 启动后端服务，确认终端显示服务已监听 3000 端口，并访问 `/api/health` 检查接口状态。
11. 启动前端服务，浏览器访问 `http://localhost:5173`，确认页面进入登录入口。
12. 在评审或演示环境中，也可按项目提供的“一键部署.bat”“一键启动.bat”和“一键停止.bat”完成部署、启动和停止。

### 2.3 首次使用准备

1. 准备一个可用的学生、教师或管理员账号。已导入演示数据时，可使用项目提供的演示账号。
2. 登录后确认页面顶部或侧边导航显示与当前角色匹配的菜单。
3. 学生首次使用时，先进入“我的课程”，确认已经加入课程或等待教师加入教学班。
4. 学生需要使用个人知识库时，准备与课程相关的 PDF、Word、Markdown 或文本资料。
5. 教师首次使用时，先确认课程、教学班、学生和题库数据已经加载，再进入学情分析或智慧备课。
6. 管理员首次使用时，先检查“角色与权限”“AI 配置”“知识文档”和“操作日志”等页面是否可访问。
7. 使用 AI、知识检索、语音、PPT 或其他生成能力前，确认管理员已经配置可用的服务；未配置时仍可使用课程、题目、任务、画像和部分本地数据功能。

## 三、用户操作流程

本分册按照教师的真实使用顺序编排：打开软件、登录、查看教师工作台、维护课程与教学班、发布任务、分析学情、智慧备课、管理资源和 AI 产物，最后退出登录。每个页面的操作说明后紧跟模拟截图标记和对应的备注表格。

### 3.1 登录软件

操作步骤：

打开浏览器，在地址栏输入前端部署地址，开发环境通常为 `http://localhost:5173`。

在登录入口选择“教师”，在账号输入框输入已注册账号，在密码输入框输入对应密码，然后点击“登录”。

认证成功后，页面跳转到教师工作台；认证失败时，登录表单保留当前输入状态并显示失败原因。

在“教学日历与课表”中切换月、周或列表视图，点击“新建提醒”填写备课、上课、作业或考试提醒；点击快捷入口进入“智慧备课”“学情分析”“发布作业”“发布考试”“班级管理”或“教学资源”。

### 3.3 管理课程、章节与教学班

从教师工作台进入“系统管理”或指定课程，查看课程、章节、知识点、教学班和学生列表。

在课程页面选择“编辑”维护课程名称、简介、章节和知识点；在教学班页面查看班级成员、授课时间和课程关联，并使用页面提供的入口进行新增、调整或查看。

需要了解学生学习情况时，点击学生列表或课程详情中的“学情分析”，进入授权范围内的聚合统计页面。

### 3.4 管理题库并发布作业考试

在教师导航点击“题库管理”，使用搜索和课程筛选查找题目，点击“新建题目”填写题型、题干、选项、答案、解析、难度和知识点关联。

在“作业考试”中点击“新建作业”或“新建考试”，选择课程和教学班，设置开放时间、截止时间、题目范围、提交规则和可见结果，然后点击“发布”。

发布后在任务列表查看状态；需要修改时点击任务卡片进入编辑，结束任务时按页面提示执行关闭或归档。

### 3.5 查看学情分析与学生分层

在教师导航点击“学情分析”，选择课程、教学班和统计时间范围，然后点击“开始分析”。

查看学习趋势、掌握度分布、知识点热力图、高频疑问、薄弱知识点、风险学生和学生分层；点击薄弱知识点查看对应课程资源，点击风险学生查看授权范围内的学习概览。

根据分析结果点击“生成教学建议”或转到智慧备课，将薄弱知识点和高频疑问作为备课输入。

### 3.6 使用智慧备课生成并审核教学材料

进入“智慧备课”，选择课程和教学大纲，点击“新建备课方案”并填写方案名称、授课章节和教学目标。

按页面阶段生成教案、重点难点、分层教学、练习、PPT 或学生讲义草稿；生成过程中查看执行状态，完成后打开对应内容。

对 AI 生成内容进行查看、编辑、锁定、优化和保存版本；完成教师审核后，点击“发布”“导出”或“发送到产物中心”。

### 3.7 管理教学资源、智能体与产物中心

进入“教学资源”或“资源审核”，按课程和状态筛选课程文件、知识文档和学生提交材料，点击文档查看解析状态、详情和可用范围。

在“智能体广场”中搜索、收藏或使用教学智能体；点击“创建智能体”填写名称、类型、简介、系统提示和知识库绑定，保存草稿后进行测试、提交发布或返回修改。

在“产物中心”查看讲义、题目、图表、PPT 或其他生成文件的任务状态，点击“预览”“下载”或“归档”。若页面提示需要审核，先完成审核再公开使用。

查看回答、执行状态和引用来源；对结果使用“重新生成”“复制”或“保存到备课方案”，必要时新建对话或管理历史会话。

在教师数据看板查看课程进度、作业完成率、知识点掌握度、错题分布、学习趋势和教学提醒，点击图表中的课程或知识点返回学情分析或备课页面。

### 3.9 退出登录并结束运行

点击页面顶部头像或账号名称，在用户菜单中点击“退出登录”。系统清理当前会话并返回登录入口。

确认回到登录页后关闭浏览器；公共设备上不保存密码、不保留登录状态，并删除下载的临时文件。

## 四、功能说明

### 4.1 教师端快捷操作

| 快捷操作 | 操作方式 | 功能说明 |
|---|---|---|
| 发送 AI 消息 | AI 输入框按 Enter | 发送教学问题；Shift+Enter 换行 |

## 五、异常处理与数据安全

### 5.1 数据安全与隐私

教师只能查看和维护被授权课程、教学班及其聚合数据。教学材料发布前应完成教师审核，AI 生成内容不得作为成绩认定、学术评价或管理处分的唯一依据；模型密钥和数据库口令只保存在后端部署环境。

| 异常现象 | 可能原因 | 处理建议 |
|---|---|---|
| 登录失败 | 账号、密码或角色选择错误 | 检查教师账号和密码，必要时联系管理员 |
| 课程或教学班为空 | 尚未授权或筛选条件不匹配 | 检查课程关系、教学班和筛选条件 |
| 作业发布失败 | 必填字段缺失或时间范围无效 | 补齐题目、教学班和时间字段后重试 |
| 学情图表无数据 | 课程、班级或时间范围未选择 | 选择有效条件并点击“开始分析” |
| AI 生成失败或超时 | 模型未配置、网络异常或服务繁忙 | 保留输入内容，重试或调整输入 |
| 资源解析失败 | 文件损坏、格式复杂或解析服务异常 | 查看失败原因，重新上传或点击“解析” |
| 生成产物处于等待状态 | 后台任务尚未完成 | 进入产物中心查看状态，避免重复提交 |
| 进入页面显示无权限 | 当前教师没有页面权限 | 返回工作台并联系管理员授权 |
| 发布内容需要审核 | 内容或智能体版本未完成审核 | 按页面提示完成审核后再公开使用 |
| 账号信息泄露风险 | 公共设备保留登录状态或导出文件 | 立即退出登录、关闭浏览器并删除临时文件 |
