## 接口规范

### 基础路径

```
开发环境：http://localhost:3000/api
```

所有接口统一使用 `/api` 前缀。

### 请求方式

- `GET`：查询数据
- `POST`：新增数据
- `PUT`：全量更新
- `PATCH`：部分更新
- `DELETE`：删除数据

### 响应格式

所有接口返回统一的 JSON 格式：

**成功响应：**

```json
{
  "code": 200,
  "message": "ok",
  "data": { ... }
}
```

**错误响应：**

```json
{
  "code": 400,
  "message": "错误描述",
  "data": null
}
```

### 字段命名

接口中的字段统一使用 **camelCase（驼峰命名）**，与数据库字段和前端保持一致。

---

## 认证方式

除登录和注册接口外，所有需要认证的接口都需要在请求头中携带 JWT Token：

```
Authorization: Bearer <token>
```

**获取 Token：** 调用登录接口成功后，响应中返回 `token` 字段。

**Token 有效期：** 默认 7 天（可通过 `JWT_EXPIRES_IN` 环境变量配置）。

前端 Axios 实例（`frontend/src/api/request.js`）已统一配置自动携带 Token。

## 公共接口

### 健康检查

用于确认后端服务是否正常运行。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 获取服务运行状态 |

**无需认证。**

**响应示例：**

```json
{
  "code": 200,
  "message": "ok",
  "data": {
    "name": "DisciMind Backend",
    "status": "running"
  }
}
```

## 认证模块

路由前缀：`/api/auth`

| 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|
| POST | `/api/auth/register` | 否 | 用户注册 |
| POST | `/api/auth/login` | 否 | 用户登录 |
| GET | `/api/auth/me` | 是 | 获取当前用户信息 |
| PATCH | `/api/auth/me` | 是 | 更新个人资料 |
| POST | `/api/auth/me/avatar` | 是 | 上传头像 |
| POST | `/api/auth/me/password` | 是 | 修改密码 |

### 注册

```
POST /api/auth/register
```

**请求体：**

```json
{
  "username": "student1",
  "password": "123456",
  "role": "student"
}
```

> `role` 可选值：`student`（学生）、`teacher`（教师）。管理员只能由已有管理员在后台创建。

### 登录

```
POST /api/auth/login
```

**请求体：**

```json
{
  "username": "student1",
  "password": "123456"
}
```

**成功响应：**

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOi...",
    "user": {
      "id": 1,
      "username": "student1",
      "role": "student",
      "realName": "学生演示"
    }
  }
}
```

## AI 模块接口

### AI 学科答疑

路由前缀：`/api/ai-chat`

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/ai-chat/conversations` | 创建 AI 对话 |
| GET | `/api/ai-chat/conversations` | 获取对话列表 |
| GET | `/api/ai-chat/starter-questions` | 获取建议问题 |
| GET | `/api/ai-chat/conversations/:conversationId/messages` | 获取对话消息 |
| POST | `/api/ai-chat/conversations/:conversationId/messages` | 发送消息（非流式） |
| POST | `/api/ai-chat/conversations/:conversationId/stream` | 发送消息（SSE 流式） |
| DELETE | `/api/ai-chat/conversations/:conversationId/messages` | 清空对话消息 |
| DELETE | `/api/ai-chat/conversations/:conversationId` | 删除对话 |

> **流式对话（SSE）说明：** `/stream` 接口使用 Server-Sent Events 方式返回 AI 回复，适合展示逐字输出效果。前端需要监听 SSE 事件来实时渲染内容。

### 智能体模块

路由前缀：`/api/agent`（通过 `backend/src/modules/agent/` 注册）

智能体广场路由：`/api/agent-market`（通过 `backend/src/modules/agent-market/` 注册）

> 智能体和智能体广场模块当前处于结构预留阶段，具体接口请参考完整 API 文档。

### Dify 转发

路由前缀：`/api/dify`（通过 `backend/src/modules/dify/` 注册）

> Dify 转发层用于封装 Dify 平台 API，前端通过后端转发请求，不直接暴露 Dify API Key。

## 错误码说明

| 错误码 | 含义 | 触发场景 |
|--------|------|----------|
| 200 | 成功 | 请求正常处理 |
| 400 | 参数错误 | 缺少必填字段、格式不正确 |
| 401 | 未登录 | Token 缺失、过期或无效 |
| 403 | 权限不足 | 角色不匹配（如学生访问教师端接口） |
| 404 | 资源不存在 | 请求的数据不存在 |
| 409 | 冲突 | 用户名已存在等 |
| 413 | 文件过大 | 上传文件超过限制 |
| 500 | 服务器错误 | 后端内部异常 |

### 错误码常量定义

后端使用以下错误码常量（定义在各 controller 和 middleware 中）：

| 常量 | 值 | 说明 |
|------|-----|------|
| 成功 | 200 | 请求成功 |
| 参数错误 | 40001 | 请求参数不合法 |
| 未登录 | 40101 | 未提供有效 Token |
| 权限不足 | 40301 | 当前角色无权访问 |
| 服务器错误 | 50001 | 服务端内部异常 |
