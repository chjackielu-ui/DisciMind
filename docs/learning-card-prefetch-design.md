# 学习知识卡片缓存与预生成设计

## 目标

Trainer 或其他长耗时节点启动后，学生立即获得可学习内容，同时正式 Agent 继续并行生成。卡片不是 Trainer 回答的替代品，也不写入 LangGraph checkpoint。

## 两层缓存

- 通用卡片：按课程、知识点、节点类型和内容版本计算稳定 key，可跨同范围会话复用。
- 个性化卡片：在通用 key 上加入认证学生和安全画像哈希，只能由本人读取。

缓存文件使用原子 JSON 写入，状态为 `generating`、`ready` 或 `failed`；包含生成时间、过期时间、来源和卡片 Schema 版本。READY 在有效期内直接命中；过期内容可先读后后台刷新。正在生成但 Worker 已重启时，GET 会通过 dedupe key 安全重新排队。

## 预生成触发

学习计划/工作流准备、学习会话打开、当前节点进入、Trainer 启动、资料或知识点发布时触发可失败的预热。实际执行复用 `LEARNING_FLOW_PRELOAD` AsyncTask Worker，不创建独立调度系统。

## 即时回退

缓存未命中时同步返回由真实课程/知识点/节点信息构造的安全回退卡片，并显示“练习正在准备，你可以先查看这些知识卡片。”后台 Qwen JSON 生成使用受控 Schema；失败时保留回退卡，不阻塞学习。

## 卡片交互

每组默认 5 张（通用 3 + 个性化 2），支持上一张、下一张、展开/收起、收藏、保存和标记掌握。用户状态独立持久化，不污染通用缓存；保存复用现有成果边界。
