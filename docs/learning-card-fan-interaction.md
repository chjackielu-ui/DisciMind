# 主页扇形卡组交互

卡组由 `createDailyLearningCardFan` 统一计算可见槽位：桌面 5 张 `[-2,-1,0,1,2]`，平板/手机 3 张 `[-1,0,1]`。位移、旋转、缩放和 z-index 都由槽位函数推导，中心卡最大；窗口较窄时收紧水平与垂直偏移，避免横向滚动。

非中心卡点击先移到中心，中心卡再打开详情；左右按钮、分页点、ArrowLeft/ArrowRight、Enter/Space 和触摸滑动共享同一状态机。移动期间只保留最后一个排队方向，当前卡 ID 在异步更新后保持。鼠标悬停使用 CSS 变量推开邻卡；`prefers-reduced-motion` 下缩短/取消位移动画。

详情在桌面为居中 dialog，在手机为底部抽屉；支持焦点圈、Tab 循环、Escape、焦点恢复和滚动锁。曝光每个卡片实例只记录一次，失败时才允许重试，避免 resize/render 造成事件膨胀。
