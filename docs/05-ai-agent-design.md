# AI 与 Agent 设计

> 当前为结构规划阶段，不代表功能已完成。

## 1. 总体路线

本项目采用 **"Dify + 自研轻量 Agent"** 双路线策略：

| 路线 | 定位 | 典型场景 |
|------|------|----------|
| Dify | 成熟 Agent / Workflow / RAG 编排平台 | 复杂工作流、知识库问答、多步推理 |
| 自研 Agent | 项目特色能力展示、轻量任务调度 | 教学演示、简单分发、Prompt 模板 |

## 2. Dify 智能体能力

- 通过 Dify API 接入外部智能体、Workflow、RAG 应用
- Dify 负责成熟的 Agent 编排和知识库管理
- 本项目后端负责封装 Dify API，前端负责展示和调用
- Dify API Key 统一由后端环境变量管理，前端不直接暴露

## 3. 自研轻量 Agent 能力

- 保留自研 Agent 调度器扩展空间
- 当前不需要实现复杂 Agent，只预留结构
- 后续可用于：
  - 轻量任务分发
  - Prompt 模板管理
  - RAG 工作流
  - 工具调用封装

## 4. 智能体广场

- 智能体广场用于统一展示和调用不同类型智能体
- 支持展示的类型：
  - Dify 智能体
  - 自研智能体
  - 教学智能体
  - 科研智能体
  - 知识库智能体
  - 内容生成智能体
- 当前只做结构预留，不实现真实页面逻辑

## 5. AI Provider 架构

规划接入以下大模型：

| Provider | 环境变量 |
|----------|----------|
| 讯飞星火 | SPARK_API_KEY、SPARK_API_SECRET、SPARK_APP_ID |
| DeepSeek | DEEPSEEK_API_KEY |
| 通义千问 | QWEN_API_KEY |

通过 Provider Factory 模式统一管理，根据配置动态选择调用哪个模型。

## 6. 开发阶段

当前处于结构规划阶段，后续按以下顺序逐步实现：

1. 后端 Dify API 封装
2. 智能体广场基础列表
3. 自研 Agent 调度器（简单版）
4. AI 对话接入
5. AI 图文视频生成
