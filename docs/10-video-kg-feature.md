# 知识图谱功能说明（学生端课程详情）

> 本文档说明在学生端课程详情页新增的「知识图谱」功能。

---

## 1. 功能概述

在课程详情页（`/student/courses/:course_id`）的课程名称旁新增 **🕸️ 知识图谱** 图标按钮。点击后打开模态弹窗，左侧展示课程的知识结构（章节 → 知识点树），右侧展示选中知识点的视频讲解列表。

---

## 2. 交互流程

```
课程详情页 → 课程名称 → [🕸️] 知识图谱按钮
       └─ 点击 → 弹出模态弹窗
            ┌─ 左侧：章节与知识点树 ─┐  ┌─ 右侧：视频讲解列表 ────┐
            │  [1] 第一章           │  │  [B站图标] PCA讲解      │
            │    ● 监督学习  ▶      │  │  [B站图标] 降维可视化   │
            │    ● 线性回归  ▶      │  │  [B站图标] 特征值原理   │
            │  [2] 第二章           │  │                        │
            │    ● 神经网络  ▶      │  │  [播放] [观看]          │
            └───────────────────────┘  └────────────────────────┘
               点击知识点 → 右侧加载视频
```

---

## 3. 知识点 → 视频搜索

| 步骤 | 说明 |
|------|------|
| 1 | 用户点击知识图谱中的某个知识点 |
| 2 | 取 `knowledge_point_name` 作为搜索关键词 |
| 3 | 调用 `POST /api/student/videos/search`（已有接口） |
| 4 | 返回视频列表，含 `embed_url`、`title`、`author`、`video_url` |
| 5 | 右侧展示视频列表，有 embed_url 的显示「播放」按钮，无则显示「观看」跳转 |

关键词来源：`knowledge_point_name`（知识点名称）
