# 软件杯复活赛提交清单

本清单对应“可完整运行的多智能体相关文件，包含项目源码、数据集、模型部署配置文件等，文件整理规范，可在常规环境下正常运行”的要求。

| 要求 | 提交内容 | 状态 |
| --- | --- | --- |
| 完整前端源码 | `frontend/src/`、`frontend/package.json`、锁文件 | 已包含 |
| 完整后端源码 | `backend/src/`、`backend/package.json`、锁文件 | 已包含 |
| 多智能体源码 | LangGraph、Planner、Skill、Tool、Agent、Trace、知识库模块 | 已包含 |
| 数据库 | Prisma Schema、全部 migrations、幂等 seed | 已包含 |
| 数据集 | `datasets/`、`backend/prisma/seed-assets/` | 已包含 |
| 模型配置 | `deploy/model/`、`backend/.env.example` | 已包含且已脱敏 |
| 在线编译沙箱 | `deploy/judge0/` | 已包含 |
| 一键部署 | `一键部署.bat`、`一键安装环境.bat` | 已包含 |
| 一键启动/停止 | `一键启动.bat`、`一键停止.bat` | 已包含 |
| 测试 | `backend/test/`、`frontend/test/`、评委包完整性检查 | 已包含 |
| 使用文档 | `评委必读.md`、`docs/评委本地运行说明.md` | 已包含 |
| 完整性证明 | 包内 `BUILD-INFO.json`、`SOURCE-MANIFEST.sha256`，包外 SHA-256 | 打包时生成 |
| 敏感信息处理 | 排除 `.env`、数据库、上传、日志、缓存、生成物 | 自动检查 |

## 提交前团队操作

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\judge-package\Build-Judge-Package.ps1
```

只提交 `release/` 中最新的 ZIP 和对应 `.sha256.txt`。不要提交 `.judge-runtime`、真实 `.env`、生产数据库导出或云服务密钥。
