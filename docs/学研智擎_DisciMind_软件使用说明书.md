## 一、软件概述

### 1.1 主要功能

学研智擎（DisciMind）是一套面向高等教育教学、学习和科研辅助场景的 Web 应用软件。软件支持学生、教师和管理员三类角色，围绕课程、知识库、人工智能问答、多智能体、学习流、练习、错题、学习画像和教学治理形成完整的使用闭环。

| 功能模块 | 主要功能 | 用户可见结果 |
|---|---|---|
| 用户认证 | 注册、登录、退出登录、角色识别 | 登录后按角色进入对应工作台 |
| 学生首页 | 学习概览、今日智学卡、待办任务、课程进度和推荐 | 显示当前学习状态及下一步操作 |
| 课程学习 | 查看课程、章节、知识点、课程资料和学习进度 | 形成课程学习地图并记录学习位置 |
| 知识图谱 | 查看章节与知识点关系、掌握度及关联资源 | 以图谱、列表和详情面板呈现知识结构 |
| 智能练习 | 配置课程、题型、难度和题量并开始练习 | 支持作答保存、提交判分和结果查看 |
| 在线编译器 | 学生选择 C 或 Python，输入代码并提交运行 | 在控制台查看编译、运行、超时或错误结果 |
| 错题管理 | 查看错题、错误原因、复习状态和相似练习 | 错题进入错题本并支持强化学习 |
| AI 学科答疑 | 选择问答模式，输入问题并查看流式回答 | 展示回答、执行进度、引用来源和追问入口 |
| 个人知识库 | 上传 PDF、Word、Markdown 或文本资料并查看解析状态 | 文档完成上传、解析、切片和详情查看 |
| 学习流 | 创建学习目标、编排学习节点、保存并执行学习流 | 按节点生成内容、完成练习并形成学习总结 |
| 智能体广场 | 发现、搜索、收藏、复制、创建和使用智能体 | 进入智能体对话或生成学习产物 |
| 教师工作台 | 课程、教学班、作业考试、学情分析、资源和智慧备课 | 教师根据授权教学数据开展教学管理 |
| 管理员治理 | 用户、课程、知识文档、AI 配置、权限、日志和安全治理 | 管理员进行审核、配置和审计操作 |

### 1.2 技术特点

1. 软件采用前后端分离的 Web 架构，用户通过浏览器完成主要操作。
2. 软件通过学生、教师和管理员角色及权限控制区分可见菜单和可执行操作。
3. 软件支持课程知识库、来源引用、文档解析和 AI 学科答疑，回答页面可展示真实资料来源。
4. 软件提供学习流和多智能体能力，用户可创建学习目标、配置节点并按顺序执行。
5. 软件提供智能练习、自动判分、错题记录、掌握度分析和个性化学习推荐。
6. 软件提供教师学情分析、智慧备课、作业考试、课程资源和产物中心。
7. 软件提供管理员的知识文档审核、AI 供应商与模型配置、操作日志、权限和 AI 安全治理。
8. 软件对文件上传、AI 调用、权限校验、页面加载和数据保存提供状态提示、失败提示和重试入口。

## 二、运行环境与部署

### 2.1 推荐运行环境

| 环境项目 | 推荐配置 |
|---|---|
| 使用终端 | 台式机、笔记本电脑或具备现代浏览器的移动终端 |
| 操作系统 | Windows 10/11、macOS 或主流 Linux 发行版 |
| 浏览器 | Chrome、Edge、Firefox 等支持 ES6、Fetch API 和现代 CSS 的浏览器 |
| 前端运行时 | Node.js 22.12 及以上版本，npm 9 及以上版本 |
| 后端运行时 | Node.js 22.12 及以上版本 |
| 数据库 | MySQL 8.0 及以上版本，字符集建议使用 utf8mb4 |
| 显示分辨率 | 桌面端建议 1280×720 及以上 |
| 前端开发地址 | `http://localhost:5173`，以实际 Vite 启动提示为准 |
| 后端接口地址 | `http://localhost:3000`，以 `backend/.env` 中的端口配置为准 |
| 网络环境 | 能够访问前端、后端和已配置的模型、知识库及文件服务 |
| 文件格式 | PDF、DOC、DOCX、TXT、Markdown 等页面允许的格式；单文件大小以页面提示为准 |
| 运行权限 | 普通用户权限即可运行；部署、数据库初始化和服务安装需要相应管理权限 |

### 2.2 部署步骤

1. 将项目目录完整复制到部署终端，确保 `frontend`、`backend`、`storage` 和 `deploy` 等目录结构完整。
2. 安装 Node.js 22.12 及以上版本，并确认 `node -v` 和 `npm -v` 可以正常执行。
3. 安装并启动 MySQL 8.0 及以上版本，创建名为 `discimind` 的数据库并使用 `utf8mb4` 字符集。
4. 进入 `backend` 目录执行 `npm install`，安装后端依赖。
5. 进入 `frontend` 目录执行 `npm install`，安装前端依赖。
6. 在 `backend/.env` 中填写数据库连接、JWT 密钥、服务端口和需要使用的 AI 服务参数；密钥只用于部署配置，不写入说明书或截图。
7. 在 `frontend/.env` 中配置后端接口地址，开发环境通常使用 `VITE_API_BASE_URL=http://localhost:3000/api`。
8. 在 `backend` 目录执行 `npx prisma generate`，再执行数据库迁移命令创建或更新表结构。
9. 如需演示数据，执行项目提供的种子数据脚本，创建学生、教师、管理员账号及课程、题目和学习记录。
10. 启动后端服务，确认终端显示服务已监听 3000 端口，并访问 `/api/health` 检查接口状态。
11. 启动前端服务，浏览器访问 `http://localhost:5173`，确认页面进入登录入口。
12. 在评审或演示环境中，也可按项目提供的“一键部署.bat”“一键启动.bat”和“一键停止.bat”完成部署、启动和停止。

### 2.3 首次使用准备

1. 准备一个可用的学生、教师或管理员账号。已导入演示数据时，可使用项目提供的演示账号。
2. 登录后确认页面顶部或侧边导航显示与当前角色匹配的菜单。
3. 学生首次使用时，先进入“我的课程”，确认已经加入课程或等待教师加入教学班。
4. 学生需要使用个人知识库时，准备与课程相关的 PDF、Word、Markdown 或文本资料。
5. 教师首次使用时，先确认课程、教学班、学生和题库数据已经加载，再进入学情分析或智慧备课。
6. 管理员首次使用时，先检查“角色与权限”“AI 配置”“知识文档”和“操作日志”等页面是否可访问。
7. 使用 AI、知识检索、语音、PPT 或其他生成能力前，确认管理员已经配置可用的服务；未配置时仍可使用课程、题目、任务、画像和部分本地数据功能。

## 三、用户操作流程

以下步骤按照“打开软件→登录→查看角色首页→完成核心业务操作→退出登录”的顺序编排。学生、教师和管理员登录后会进入不同的首页，用户只会看到当前角色允许访问的功能入口。

### 3.1 登录软件

操作步骤：

1. 打开浏览器，在地址栏输入前端部署地址，开发环境通常为 `http://localhost:5173`。
2. 在登录入口选择身份类型：学生、教师或管理员。
3. 在账号输入框中输入已注册的账号或用户名。
4. 在密码输入框中输入账号对应的密码。
5. 点击“登录”按钮，等待系统完成认证。
6. 登录成功后，系统保存当前会话状态，并按角色跳转到学生首页、教师工作台或管理员首页。
7. 登录失败时，页面保留登录表单并显示失败原因；用户可检查输入内容后再次提交。
8. 尚未注册的用户可点击“注册”进入注册页面；注册字段按所选择的公开角色显示。

### 3.2 查看角色首页与学习概览

学生操作步骤：

1. 登录成功后进入“首页”，查看学习概览、今日智学卡、待办与任务、推荐与薄弱项、课程进度和教师下发资料。
2. 查看“学习概览”中的学习进度、已掌握知识点、学习活跃度和未解决错题等指标。
3. 点击“继续学习”“查看课程”“任务中心”或“全部推荐”等按钮，进入下一步业务页面。
4. 点击课程卡片可以打开课程详情，点击推荐或薄弱知识点可以进入智能练习、学习流或推荐页面。

教师操作步骤：

1. 登录成功后进入“教师工作台”，查看负责课程、教学班、学生人数和本周教学安排。
2. 在“教学日历与课表”中切换月、周、列表视图，点击“新建提醒”安排备课、上课、作业或考试提醒。
3. 通过快捷入口进入“智慧备课”“学情分析”“发布作业”“发布考试”“班级管理”或“教学资源”。

管理员操作步骤：

1. 登录成功后进入管理员首页，查看用户、课程、知识文档、AI 调用、安全风险和系统服务状态。
2. 根据权限进入“用户管理”“教学管理”“AI 配置”“内容与审核”“AI 安全治理”或“系统管理”。

### 3.3 查看课程、章节与知识图谱

学生操作步骤：

1. 在左侧导航点击“我的课程”。
2. 在课程列表中使用搜索框输入课程名称或课程代码，也可按学习进度、课程名称或薄弱知识点排序。
3. 点击课程卡片的“开始学习”或“继续学习”，进入课程详情。
4. 在课程详情中查看课程进度、章节学习地图、知识点列表、课程资料、课程视频和课程能力画像。
5. 点击“知识图谱”，查看章节、知识点和关联知识点的层级关系。
6. 选择一个知识点，查看掌握度、难度、学习建议、相关资源和关联知识点。
7. 点击“训练师诊断”进入针对知识点的诊断练习；点击“学习流”进入与该知识点关联的学习流程。
8. 需要运行课程代码时，点击课程详情中的“在线编译器”，选择 C 或 Python，输入代码并点击“运行”，在控制台查看编译、运行、超时或错误结果。
9. 使用知识点搜索、章节筛选、掌握状态筛选或卡片类型筛选定位学习内容。

教师操作步骤：

1. 从教师工作台进入“系统管理”或对应课程。
2. 查看课程、章节、知识点和教学班信息。
3. 根据页面提供的入口进入课程详情、学生列表、教学班工作区或资源审核页面。

### 3.4 进行智能练习、提交答题并查看错题

操作步骤：

1. 在学生端点击“智能学习”，进入“智能练习中心”。
2. 选择一门课程，确认题库数量和当前错题数量。
3. 在“练习设置”中选择练习或考试模式，设置题型、难度、题量，以及题库题和 AI 动态生成题的组成比例。
4. 点击“开始练习”，进入作答页面。
5. 按题号导航查看题目，在选项、文本框或答题区域输入答案。
6. 练习模式下，系统自动保存答案；考试模式按页面提示完成提交。
7. 点击“提交本题”或“提交整卷”，等待系统判分。
8. 提交成功后查看得分构成、题型得分、每题结果、题目解析和学习建议。
9. 对错误题目点击“查看解析”或“生成 AI 解析”，必要时进入“错题本”继续复习。
10. 在“错题本”中按课程、章节、知识点、错误原因或复习状态筛选错题，并开始强化练习或查看相似题。

### 3.5 使用 AI 学科答疑与查看知识库来源

操作步骤：

1. 在学生导航点击“AI 对话”，进入学科答疑页面。
2. 在问答模式中选择“通用问答”或“学科答疑”；学科答疑会绑定当前课程或授权知识库。
3. 在输入框中输入问题，例如“请解释监督学习与无监督学习的区别”。
4. 如页面提供“@”引用入口，可选择知识库；如提供“\”智能体入口，可选择可用智能体。
5. 点击“发送”，页面显示问题处理状态、知识库检索状态或智能体执行状态。
6. 等待回答逐步显示，必要时使用“重新生成”“复制”“朗读”或“清空对话”等操作。
7. 展开“查看真实资料来源”，查看来源文件、知识库名称、页码或片段信息。
8. 如需继续追问，在当前对话输入下一条问题；如需新的主题，点击“新建对话”。
9. 在历史会话区域搜索、重命名、删除或批量管理已有会话。

### 3.7 创建并执行个性化学习流

5. 从节点库中选择概念讲解、例题分析、基础练习、自适应练习、错题修复、掌握度判断和学习总结等节点。
6. 将节点拖入画布，按照希望的学习顺序排列；使用节点面板填写标题、说明或输入要求。

## 五、异常处理与数据安全

### 5.1 数据安全与隐私

1. 用户认证使用登录令牌保护受限页面；令牌失效或接口返回未授权时，页面清理本地登录状态并返回登录入口。
2. 用户密码由后端进行安全处理，说明书、截图和演示数据不得包含真实密码。
3. AI 服务密钥、数据库口令、JWT 密钥和对象存储凭据只保存在后端部署环境，前端页面不回显真实值。
4. 学生学习数据按账号隔离，教师只可查看授权课程和教学班的聚合信息，管理员按权限查看治理数据。
5. 上传的学习资料应与业务有关，不得包含无关个人身份信息、联系方式、住址、账号口令或第三方密钥。
6. AI 生成内容需要人工核验；教师生成的教学材料在发布前应完成审核，管理员治理操作保留审计记录。
7. 部署人员应定期备份数据库、上传文件、解析文件和必要的运行日志，并限制存储目录的访问权限。

异常处理对照表如下。

| 异常现象 | 可能原因 | 处理建议 |
|---|---|---|
| 登录失败 | 账号、密码或角色选择错误 | 检查账号、密码和身份入口；必要时重新注册或联系管理员 |
| 页面无法打开 | 前端未启动、地址错误或端口被占用 | 检查 Vite 服务、访问地址和浏览器控制台 |
| 接口请求失败 | 后端未启动、API 地址错误或数据库连接异常 | 检查 Node.js 服务、`VITE_API_BASE_URL` 和后端日志 |
| 进入页面后显示无权限 | 当前角色未被授予页面权限 | 返回本角色首页，联系管理员调整显式权限 |
| 课程或教学班为空 | 尚未加入课程、未绑定教学班或筛选条件不匹配 | 检查课程关系和筛选条件，联系教师或管理员 |
| 文档上传失败 | 格式、大小、网络或存储目录权限不符合要求 | 更换符合要求的文件，检查文件大小和存储权限后重试 |
| 文档解析失败 | 文件损坏、格式结构复杂或解析服务暂时不可用 | 查看失败原因，重新上传或点击“解析”重试 |
| AI 回答失败或超时 | 模型服务未配置、网络异常或服务繁忙 | 保留问题内容，重试、切换模式或稍后再试 |
| 回答没有来源 | 知识库未绑定、资料未命中或当前模式不要求来源 | 检查知识库状态，结合课程资料人工核验 |
| 学习流节点执行失败 | 节点输入不完整或 AI/知识库服务不可用 | 按页面提供的“重新尝试”“跳过节点”或“返回”处理 |
| 练习答案未保存 | 网络异常、会话失效或考试模式不保存进度 | 检查保存状态；考试模式按页面规则完成提交 |
| 提交结果未生成 | 答案未提交完整或服务处理中 | 等待页面返回结果，确认题目状态后再次提交 |
| 错题本无数据 | 尚未完成练习或当前筛选范围无错题 | 完成一次练习并清除不必要的筛选条件 |
| 图表无数据 | 时间范围、课程或教学班未选择 | 选择有效课程和统计范围后点击“开始分析” |
| 产物生成中 | 后台任务尚未完成 | 进入任务中心查看状态，不要重复提交同一任务 |
| 管理员配置测试失败 | Base URL、模型参数或密钥不可用 | 检查配置状态，替换密钥并重新测试连接 |
| 安全规范同步失败 | 服务异常或当前管理员权限不足 | 检查权限和后端服务，稍后重试并查看操作日志 |
| 账号信息泄露风险 | 在公共设备保存了登录状态或导出文件 | 立即退出登录、关闭浏览器并删除临时文件 |
| 重复提交 | 连续点击保存、生成、发布或审核按钮 | 等待页面返回状态后再继续操作 |
