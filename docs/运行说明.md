## 环境准备

### 必需软件

在开始之前，请确保你的电脑已安装以下软件：

| 软件 | 最低版本 | 检查命令 | 下载地址 |
|------|----------|----------|----------|
| Node.js | v18.0.0+ | `node -v` | https://nodejs.org |
| npm | v9.0.0+ | `npm -v` | 随 Node.js 安装 |
| MySQL | v8.0+ | `mysql --version` | https://dev.mysql.com/downloads/mysql/ |

### 安装 Node.js

**Windows 用户推荐使用 nvm-windows：**

1. 下载 nvm-windows：https://github.com/coreybutler/nvm-windows/releases
2. 安装后打开终端，执行：
   ```bash
   nvm install 18
   nvm use 18
   ```

**或直接下载 Node.js 安装包：**

1. 访问 https://nodejs.org
2. 下载 LTS 版本（v18 或更高）
3. 双击安装，一直点击"下一步"即可

### 安装 MySQL

**Windows 用户推荐方案一：使用 XAMPP（简单）**

1. 下载 XAMPP：https://www.apachefriends.org
2. 安装后打开 XAMPP Control Panel
3. 点击 MySQL 旁边的 "Start" 按钮启动 MySQL

**Windows 用户推荐方案二：MySQL Community Server**

1. 下载 MySQL Installer：https://dev.mysql.com/downloads/installer/
2. 安装时选择 "Server only"
3. 记住你设置的 root 密码（后面配置环境变量需要用）

## 项目获取

### 方式一：通过 Git 克隆

```bash
git clone <项目仓库地址>
cd DisciMind
```

### 方式二：直接拷贝项目文件夹

将整个 `DisciMind` 文件夹拷贝到目标电脑，然后进入该目录。

> **注意：** 项目中的 `node_modules/` 文件夹不需要拷贝，拷贝后需要重新安装依赖。

## 依赖安装

在项目根目录下，分别安装前端和后端依赖：

```bash
# 第一步：安装后端依赖
cd backend
npm install

# 第二步：安装前端依赖
cd ../frontend
npm install

# 第三步：回到项目根目录
cd ..
```

执行 `npm install` 后会在 `backend/node_modules/` 和 `frontend/node_modules/` 目录下生成所有依赖包。

如果安装速度很慢，可以设置 npm 镜像：

```bash
npm config set registry https://registry.npmmirror.com
```

## 数据库配置

### 1. 启动 MySQL 服务

确保 MySQL 服务正在运行。不同安装方式的检查方法：

- **XAMPP：** 在 XAMPP Control Panel 中确认 MySQL 显示绿色 "Running" 状态
- **MySQL Community Server：** 在 Windows 服务中查找 `MySQL80`，确保状态为"正在运行"
- **命令行检查：**
  ```bash
  mysql -u root -p
  ```
  如果能成功登录，说明 MySQL 已启动

### 2. 创建数据库

登录 MySQL 后，执行以下 SQL 命令创建数据库：

```sql
CREATE DATABASE discimind CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

创建成功后，可以用以下命令验证：

```sql
SHOW DATABASES;
```

你应该能在列表中看到 `discimind`。

## 环境变量配置

### 后端环境变量

在 `backend/` 目录下创建 `.env` 文件：

```bash
# 进入后端目录
cd backend

# 复制示例文件（如果 backend/.env.example 存在）
copy .env.example .env

# 如果不存在 .env.example，参考项目根目录的 .env.example
copy ..\.env.example .env
```

然后编辑 `backend/.env` 文件，**至少需要修改以下两项**：

```env
# 数据库连接 - 将 root 和后面的密码改为你的 MySQL 用户名和密码
DATABASE_URL="mysql://root:你的MySQL密码@localhost:3306/discimind"

# JWT 密钥 - 改为随机字符串（可以随便输入一串字符）
JWT_SECRET="你的JWT密钥"
```

完整的环境变量说明请参考 [backend/.env.example](../backend/.env.example)。

### 前端环境变量

在 `frontend/` 目录下创建 `.env` 文件：

```bash
cd frontend

# 复制示例文件
copy .env.example .env
```

大多数情况下，前端 `.env` 使用默认值即可：

```env
VITE_API_BASE_URL=http://localhost:3000/api
```

> **说明：** `VITE_API_BASE_URL` 告诉前端去哪里请求后端 API。如果后端运行在其他地址或端口，需要相应修改。

## 数据库初始化

环境变量配置完成后，执行 Prisma 迁移来创建数据库表：

```bash
cd backend

# 第一步：生成 Prisma 客户端（必须执行）
npx prisma generate

# 第二步：执行数据库迁移（自动创建所有表）
npx prisma migrate dev --name init
```

迁移执行成功后，终端会显示类似以下信息：

```
Applying migration `xxxxxxxxxxxxxx_init`
The following migration has been applied:
  migrations/xxxxxxxxxxxxxx_init/
  
Your database is now in sync with your schema.
```

### （可选）导入种子数据

种子数据包含演示账号和测试数据，方便快速体验系统功能：

```bash
node prisma/seed.js
```

导入成功后会显示：

```
✅ 种子数据导入完成
演示账号：
  管理员：admin_demo / 123456
  教师：teacher_demo / 123456
  学生：student_demo / 123456
```

## 启动项目

项目需要**同时启动前端和后端**。建议打开两个终端窗口，分别启动。

### 启动后端（终端一）

```bash
cd backend
npm run dev
```

启动成功后会看到：

```
[db] 数据库连接成功
DisciMind backend server is running at http://localhost:3000
```

> **提示：** `npm run dev` 使用 nodemon 启动，修改代码后会自动重启，无需手动操作。

### 启动前端（终端二）

```bash
cd frontend
npm run dev
```

启动成功后会看到：

```
VITE v8.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
```

## 常见问题

### Q1：`npm install` 失败或很慢

**原因：** 网络问题导致 npm 下载缓慢或失败。

**解决方案：** 设置国内 npm 镜像源：

```bash
npm config set registry https://registry.npmmirror.com
```

然后重新执行 `npm install`。

---

### Q2：启动后端时报错 `[db] 数据库连接失败`

**原因：** MySQL 未启动，或 `.env` 中的数据库连接配置不正确。

**解决方案：**

1. 确认 MySQL 服务已启动（检查 XAMPP 面板或 Windows 服务）
2. 检查 `backend/.env` 中的 `DATABASE_URL` 是否正确：
   - 用户名是否正确（通常是 `root`）
   - 密码是否正确
   - 端口是否正确（默认 `3306`）
   - 数据库 `discimind` 是否已创建

---

### Q3：启动后端时报错 `Cannot find module '@prisma/client'`

**原因：** 未生成 Prisma 客户端。

**解决方案：**

```bash
cd backend
npx prisma generate
```

---

### Q4：执行 `prisma migrate dev` 报错

**原因：** 数据库未创建，或数据库连接配置有误。

**解决方案：**

1. 确认已创建 `discimind` 数据库
2. 检查 `DATABASE_URL` 配置
3. 如果是权限问题，确认 MySQL 用户有创建表的权限

---

### Q5：前端页面打开但无法登录（网络请求失败）

**原因：** 后端未启动，或前端 API 地址配置不正确。

**解决方案：**

1. 确认后端已启动并正常运行
2. 检查 `frontend/.env` 中的 `VITE_API_BASE_URL` 是否指向正确的后端地址
3. 修改 `frontend/.env` 后需要重启前端开发服务器

---

### Q6：登录后页面空白或报错

**原因：** 可能是数据库表结构不完整。

**解决方案：**

1. 确认已执行 `npx prisma migrate dev` 创建所有表
2. 如果之前执行过迁移但表不完整，可以尝试：
   ```bash
   cd backend
   npx prisma migrate reset  # 重置数据库（会删除所有数据）
   ```

---

### Q7：端口被占用

**现象：** 启动时报错 `address already in use :::3000` 或 `Port 5173 is already in use`

**解决方案：**

- **后端端口（3000）被占用：** 修改 `backend/.env` 中的 `PORT=3000` 为其他端口（如 `3001`），同时修改 `frontend/.env` 中的 `VITE_API_BASE_URL` 对应端口。
- **前端端口（5173）被占用：** Vite 通常会自动尝试下一个可用端口，无需手动处理。

---

### Q8：如何查看数据库中的数据

**方式一：使用 Prisma Studio（推荐）**

```bash
cd backend
npx prisma studio
```

浏览器会自动打开 Prisma Studio 界面，可以直观地查看和编辑数据。

**方式二：使用命令行**

```bash
mysql -u root -p
USE discimind;
SHOW TABLES;
SELECT * FROM User;
```

## 生产部署

以下为基本的生产部署步骤，供参考：

### 1. 构建前端

```bash
cd frontend
npm run build
```

构建产物在 `frontend/dist/` 目录下，可直接部署到 Nginx 等 Web 服务器。

### 2. 启动后端（生产模式）

```bash
cd backend
npm run start
```

生产模式下建议使用 PM2 等进程管理工具：

```bash
npm install -g pm2
cd backend
pm2 start src/server.js --name discimind-backend
```

### 3. 配置 Nginx（可选）

将前端构建产物放到 Nginx 的静态文件目录，并配置反向代理将 `/api` 请求转发到后端。

示例 Nginx 配置：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    root /path/to/frontend/dist;
    index index.html;

    # SPA 路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
