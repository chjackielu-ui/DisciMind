# DisciMind（学研智擎）评委版本地运行说明

本评委包面向 **64 位 Windows 10/11**。评委无需预先安装 Node.js、npm、MySQL 或 MariaDB，也无需配置系统环境变量或取得管理员权限。

## 两步启动

1. 将整个 `DisciMind-评委版` 文件夹完整解压到本地磁盘。请勿直接在 ZIP 压缩包内运行脚本。
2. 双击根目录的 **`一键安装环境.bat`**，等待窗口显示“环境安装完成”。首次安装通常需要 10～30 分钟，并需要稳定的互联网连接和至少 3 GB 可用磁盘空间。
3. 双击根目录的 **`一键启动.bat`**。脚本会启动数据库、后端和前端，检查服务就绪后自动打开浏览器。

以后再次演示只需双击 `一键启动.bat`。脚本可重复运行，已经启动的服务不会被重复启动。

## 安装脚本会做什么

- 下载并校验官方 64 位便携版 Node.js 22 和 MariaDB 11.4；
- 把运行环境放到项目内的 `.judge-runtime`，不修改系统 `PATH`，不注册 Windows 服务；
- 自动生成随机数据库密码、JWT 密钥和 AI 配置加密密钥，仅保存在当前项目目录；
- 使用 `npm ci` 按锁文件安装前后端依赖；
- 使用 `prisma migrate deploy` 仅应用尚未执行的迁移，不执行 `reset`、删库或清空数据；
- 幂等注入管理员、教师、学生演示账号以及课程、题目、学习记录等展示数据；
- 完成一次前端构建检查，提前发现文件不完整或依赖异常。

下载来源：[Node.js 官方发布目录](https://nodejs.org/dist/)和 [MariaDB 官方归档](https://archive.mariadb.org/)。安装脚本内固定了压缩包的 SHA-256，校验不一致时会拒绝使用。

## 数据和日志位置

- 本地数据库：`.judge-runtime\data\mariadb`
- 随机本机配置：`.judge-runtime\config\judge-config.json`
- 安装和运行日志：`.judge-runtime\logs`
- 后端端口：`3000`
- 前端端口：`5173`
- 数据库端口：首次安装时从 `3307～3399` 自动选择并保存

关闭窗口或浏览器不会删除数据。再次启动后，演示进度仍会保留。

## 常见问题

### 提示脚本无法运行

确认项目已完整解压，且 `scripts\judge-package` 目录存在。根目录 BAT 已使用 Windows 自带 PowerShell 的一次性 `ExecutionPolicy Bypass`，不会永久修改系统执行策略。

### 下载失败或依赖安装缓慢

检查网络、代理、防火墙或校园网限制后重新双击安装脚本。Node.js 与 MariaDB 下载支持自动重试和断点续传，连接中断后会保留 `.partial` 文件；再次运行安装脚本会从断点继续。npm 官方源失败时，脚本会自动使用国内镜像重试一次。已经下载并校验成功的文件会复用，不需要从头下载。

如需预放官方运行时压缩包，可新建 `scripts\judge-package\cache`，放入以下文件，安装脚本会优先使用并校验：

- `node-v22.23.1-win-x64.zip`
- `mariadb-11.4.7-winx64.zip`

前后端 npm 依赖仍需要网络下载。

### 提示 3000 或 5173 端口被占用

关闭占用该端口的软件后再次运行。脚本不会强行结束评委电脑上的其他程序。

### 页面打不开或服务启动失败

查看 `.judge-runtime\logs` 下的 `backend-error.log`、`frontend-error.log` 和 `mariadb-error.log`。也可以重新双击 `一键启动.bat`，脚本会重新检查各服务。

### 如何停止本项目服务

重新启动电脑会自然停止所有便携服务。如需立即停止，可在项目根目录打开 PowerShell，运行：

```powershell
foreach ($pidFile in @('.judge-runtime\frontend.pid', '.judge-runtime\backend.pid', '.judge-runtime\mariadb.pid')) {
  if (Test-Path $pidFile) {
    $processId = [int](Get-Content $pidFile)
    Stop-Process -Id $processId -ErrorAction SilentlyContinue
  }
}
```

### AI 功能提示未配置供应商

评委版本不内置团队的真实第三方 AI 密钥，避免在交付包中泄露密钥。无需外部模型的课程、题目、学情、任务、权限和治理演示可正常使用；依赖在线大模型的功能需由管理员在“AI 配置”中填入合法供应商配置后使用。PPT 生成功能默认使用内置演示模式。

## 团队打包方式

在所有代码和演示数据修改完成后，从项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\judge-package\Build-Judge-Package.ps1
```

脚本会在 `release` 目录生成 ZIP 和对应的 SHA-256 文件，并自动排除 `.git`、真实 `.env`、`node_modules`、本地数据库、日志、缓存和临时产物。最终 ZIP 根目录内会保留评委需要双击的两个 BAT 文件。
