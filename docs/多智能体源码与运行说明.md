# DisciMind 多智能体源码与运行说明

## 1. 实现概览

DisciMind 的多智能体能力不是静态页面模拟。后端使用 LangChain + LangGraph，将请求规划、Skill 匹配、Agent 选择、工具调用、知识检索、过程事件、结果综合和持久化 Trace 串成统一执行链：

```text
用户请求 -> Workflow Planner -> Skill Registry -> Agent Registry
        -> Tool Registry / Knowledge -> 多 Agent 串行或并行执行
        -> 结果综合 -> Trace / 会话 / 成果持久化
```

多 Agent 默认串行并显式传递前序结果；请求明确要求并行时使用独立分支并发执行，最后统一综合。单分支失败会保留成功分支，全部失败才终止任务。

## 3. 内置角色 Agent

- Explainer：结合课程和知识库进行分层讲解。
- Diagnostician：根据答题、掌握度和行为数据定位薄弱点。
- Trainer：生成受知识点与难度约束的训练任务。
- Lesson Plan Collector / Analyzer / Generator：完成教案采集、分析和生成。
- File Generator：生成讲义、试卷、DOCX、PDF、PPT 等成果。
- 用户自定义 MODEL Agent：通过智能体广场创建版本、发布、审核、调用和复用。

## 4. 数据、模型与可复现性

- 演示数据库由 `backend/prisma/seed.js` 与 `backend/prisma/seed-judge-demo.js` 幂等生成。
- 公共知识库原始材料位于 `backend/prisma/seed-assets/408-public-knowledge.md`。
- 独立评测数据位于 `datasets/`，全部为团队编写或合成，不含个人信息。
- 模型采用阿里云百炼 OpenAI 兼容接口，配置见 `deploy/model/bailian.env.example`；不分发第三方模型权重或密钥。
- 未配置在线模型时不会伪造模型回答，依赖模型的入口会返回明确配置错误；PPT 可使用 `demo` 模式展示完整交互链。

## 5. 安全边界

- API Key 仅保存在后端运行环境或加密配置表，不进入前端和提交包。
- Agent、Skill、Tool、课程、知识库均在后端重复校验角色和所有权。
- Tool Registry 不提供任意 Shell、SQL、任意 URL 抓取或直接代码执行。
- C/Python 用户代码只经 Judge0 isolate 沙箱执行，浏览器不能访问 Judge0。
- 高风险写文件工具要求显式确认，并限制大小、格式、路径和下载权限。

更多协议细节见 `docs/ai-orchestrator-design.md`、`docs/ai-function-skill-agent.md` 和 `docs/13-agent-workflow-design.md`。
